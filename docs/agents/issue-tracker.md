# Issue tracker: GitHub

Specs and tickets live in https://github.com/sagikazarmark/cryptbox/issues.
Use the gh CLI for all tracker operations.

- Read issues with their bodies, labels, and comments.
- Create issues with a descriptive title and a Markdown body via --body-file.
- Use the label vocabulary in triage-labels.md.
- Before creating tickets, check for existing work covering the same outcome.
- Represent blocking relationships with native GitHub issue dependencies;
  use explicit "Blocked by" links if native dependencies are unavailable.
- When a skill says "publish to the issue tracker", create a GitHub issue.

PRs as a request surface: no.
